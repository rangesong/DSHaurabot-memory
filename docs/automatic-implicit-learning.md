# 经验自动成熟与内隐准则

0.7.0在现有反馈、图式和中枢规则之间补齐自动成熟。符合门槛的互动经验在夜间用同一规范ID迁入内隐层，按当前聊天与情境进入Aurabot的表达参考。最终回复仍由宿主模型生成和发送。

## 怎样成熟

1. 先关联用户输入、实际观察到的机器人回复和用户反应。群聊仍要求明确回复目标与相同互动者。
2. 同情境的独立反馈形成有来源的互动图式。模糊反应须完成现有语境复核，或由用户明确解释；单纯重复“摸摸头”不跳过检查。
3. 夜间检查独立来源根、独立轮次、自然日跨度、方向一致性及来源权限。默认至少3次经历、2个北京时间自然日，目标方向获得至少75%的有效依据支持。
4. 检查通过后，同一对象进入内隐试用；只在匹配情境中小幅调整表达参数和固定的表达提示，原始对话及必要版本继续保留。
5. 之后真正用过准则的轮次产生新反馈，才可用于验证。训练根、训练轮次、重复反馈和沉默不能重复算作成功；默认3次独立支持后标为已有后续支持。

当前支持回答细致度、追问压力、语言贴近，以及接住安慰、温和玩闹和亲近表达。明确认可可支持已实际采用的表达方向；明确的冗长／追问纠正也可形成有依据的图式。更广泛的事实推理、自动改权限或模型权重训练不在本实现内。

## 查看、暂停和撤回

打开“反馈与学习 → 经验成熟与内隐准则”。候选、单条准则和依据子栏目默认收起；展开后可查看门槛不足的原因、独立经历数、自然日数、来源详情、试用／验证阶段和历史记录。

暂停或撤回后，准则退出内隐作用，不会由夜间重新启用。普通记忆装配和同会话短期提示缓存也不能把停用准则继续当作有效偏好。查看对象、原话及历史仍可用；如需重新使用，可在星图的“行为准则”编辑器完成明确核对后由人工接管。

后续明确不满意或纠正会立即暂停；依据被更正、删除、移入群聊废弃库或变为无权限，以及用户更改表达参数，也会停止应用。原始事实不会因表达学习而被改写。其它独立且有效的用户要求继续按原规则生效。

## 调节与运行

| 参数 | 作用 |
| --- | --- |
| W3.auto_implicit_enabled | 默认1；控制自动成熟和自动准则的应用，关闭不删除经验、不影响人工准则 |
| W3.auto_implicit_min_days | 默认2；成熟证据至少覆盖的北京时间自然日数 |
| W3.implicit_min_evidence | 默认3；同情境独立反馈门槛，重复来源和同轮不加计 |
| W3.feedback_learning_rate、W5.learning_rate | 与独立证据数共同决定小幅调整速度 |
| W3.learning_step_cap | 单项表达偏移上限；0时不产生自动偏移 |
| W5.strategy_trial_feedback | 默认3；试用后需要的独立支持次数 |

成熟、门槛检查、应用和后续验证在本地执行，不新增模型调用。模糊语境的模型复核沿用已有共享日额度，额度用尽继续等待，不凭空补造复核结果。未进入夜间窗口、依据不足或交接未完成时不为填满星图而强行晋升。

自动准则只属于原人格、原聊天范围；适用条件匹配后才应用。新纠正与本轮明确要求优先，人工中枢规则优先；不修改主人的普通记忆保留期、原生memory设置或鱼的世界窗口配置。

## 验证与恢复边界

测试贯穿实际Thinkstar宿主适配、模型请求内容和完成回执，使用隔离数据与提供商替身，验证进入内隐、相似／无关情境、暂停缓存、撤回不复活、来源更正、群聊到期、重启和面板操作。提供商替身的差异用于证明软件链路，不能冒充真实模型质量提升或QQ投递成功。

数据库schema保持2，无新业务表。新增准则元数据保存在既有记忆属性及历史版本中。发布前先做隔离验证；程序更新沿用旧代码云端下载恢复验证。代码回退不会自动撤销已有学习记录，旧代码也不能被视为已经验证能继续执行新型自动准则；恢复应以当前停用状态、必要原证据及本机恢复点为准。
