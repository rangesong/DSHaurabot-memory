# 夜间与后台修复

Thinkstar 0.7.4 的专用只读桥调用 DSH 当前 web 提供方，兼容已安装的免费搜索插件。工具输出保留来源与摘要/正文区别；空结果、仅确认符号和业务失败不算读到资料。抓取及视频、帖子链接必须来自当前行动搜索结果；停用后不接受在途结果，并对支持取消的服务传递取消信号。每轮六次工具、01:00–05:00 及原每日轮次限制继续生效。

模块启动时最多检查一百个具有已完成阅读的稳定记录，只纠正回执全部明确为空、确认或失败的旧完成标签。原观察、问答、来源、记忆及回执完整保留，附原状态与复核说明。未知内容、缺回执、真实阅读与练习不变，不重新执行历史任务。数据库 schema 不变；回退代码不能撤销此标签纠正，应以复核元数据和最新记录另行审阅，不能恢复旧数据库覆盖新历史。

原生补丁限 Aurabot 1.3.0-beta.1 的已审阅文件哈希，拒绝未知版本。预检：

```powershell
node scripts/update-aurabot-module.js --data-dir <Aurabot数据绝对路径> --native-host <dsh-aurabot-qq包绝对路径> --repair-background
```

应用时加 `--apply --host-origin http://127.0.0.1:<当前插件端口>`，更新器在归档前及替换前核实相关宿主会话空闲。统一更新器归档完整允许公开的旧程序，上传既有 GitHub Releases，公开下载并落盘恢复校验通过后才替换。完成后用原生维护的 official host reload，并检查加载、连接及错误；不以磁盘哈希代替运行验收。此补丁不修改登录、主动分享、时间表或额度设置。

自驱修正异步审计计数与当日报告任务范围；动作预算满时跳过候选模型预审，已有任务推进、日报及每日去重仍沿用原规则。旧日报原文保留，新日报使用修复后的统计。

本机差分测试须显式指定已校验的旧程序基线：`BACKUP_CAPACITY_HOST_ROOT` 指向旧宿主程序目录；自驱使用 `AURABOT_SOURCE` 配合 `AURABOT_AUTOTELIC_BASELINE` 和 `AURABOT_AUTOTELIC_REFLECT_BASELINE`。已打补丁的现行程序不能充当未修复对照。没有对应基线时，测试明确跳过这些宿主集成项，纯函数测试照常执行。

备份使用兼容旧小 ZIP 的有界 ZIP64 扩展，支持总包超过 4GiB；容器上限 9GiB，解压总量仍限 8GiB、单文件仍小于 2GiB，CRC、路径、压缩及身份检查继续生效。WebDAV 上传/恢复与宿主导入使用流，Gitee 按既有 95MiB 分块，避免整包载入内存。旧 ZIP32 可恢复；超限仍明确失败，不删除真实数据来减小备份。合成测试不上传私人备份，真实远端可用性另看下一次授权或定时备份回执。

B站凭据失效需要重新登录；代码不会绕过认证。热榜上游限流/服务错误已有回退和冷却。鱼世界 1.3.12 已修复旧投递未确认阻止安全换窗；投递不确认仍保留原语义，不自动重发。
