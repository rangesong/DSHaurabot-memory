# 0.3.5：DSH 内嵌星图加载优化

## 0.3.13：模块首屏与简洁视图

进入 Thinkstar 模块即创建并展开星图，星图卡片通过自身布局顺序位于宿主设置表单之前；保留宿主原有参数定义、保存方式和设置卡片。星图地址为本模块固定挂载路径，不再等待 `/status` 返回才能挂载 iframe。底部“运行状态与说明”默认折叠，只有展开后才读取完整状态；展开期间15秒刷新一次，未完成的读取合并，收起或卸载停止刷新。状态慢或失败时，星图仍独立加载。星图收起/展开继续保留同一个 iframe 和模型，并发送显式暂停/恢复消息。

移除品牌顶部栏、标语和画布内状态文字，整幅页面用于星图；区域名称及操作按钮保留。模型配置和实现说明入口放在左侧目录的折叠说明中；图例、模型预载状态、对象计数与影像来源和许可随说明展开查看。相机不再为原标语预留顶部空间，WebGL与星点仍使用同一投影。记忆处理、数据库结构、参数、原始GLB和渲染质量均不变。

更新日期：2026-11-15。模型资源仍为 1.0.0，原始 GLB、面数、三张 4K 贴图、材质、高光、透明度和绘制分辨率设置均未降低。

## 首屏与前后台

0.3.17处理DSH内嵌画布的抓手指针显示异常：画布CSS及拖动事件不再设置grab/grabbing；空白处、拖动、移出和结束操作时使用default箭头，可点击星点继续使用常规pointer。只替换光标样式，不改相机手势或图形效果。

0.3.16修正内嵌焦点交接：宿主的blur事件不再无条件停绘，待同一轮焦点事件完成后核对宿主/子页；两者任一获得焦点且未隐藏即可继续。重复前台通知合并快照读取，每秒轻量核对可补偿宿主遗漏的恢复通知或帧循环短暂停止；已完成快照直接复用，不因此重复取图。首次读取失败等待显式重试，避免失败轮询冲击数据库；已有快照时临时刷新失败仅提示继续显示旧快照，不阻挡操控，后续正常定时刷新恢复。真正后台、隐藏面板及页面离开仍暂停。

帧循环与外层播放控制使用同一套前台判断。DSH 在前台时，内嵌页无需先取得键盘焦点即可绘制；窗口退至后台继续暂停动画与轮询。首次星图快照准备后先绘制星点、区域、雾气和通道，再在下一帧动态导入 Three.js 和女孩模型。最近轨迹改为随后异步载入，不再阻塞首屏；合并轨迹时保留去重、顺序和单调游标，未执行新的记忆任务。

## 模型复用与缓存

同一 Thinkstar 模块面板内，“收起星图”隐藏 iframe 并显式通知其暂停，“打开星图”恢复同一页面、相机和模型，在刷新最新状态后恢复绘制。消息只接受同源父窗口的明确布尔可见状态。隐藏期间不播放动画或轮询；重新展开强制补绘一次模型帧，随后继续复用静态画面。

离开模块面板、模块更新或页面关闭时仍释放页面与图形资源。收起时保留已加载的内存和显存以换取快速展开；这里没有把保留资源误称为释放资源。

GLB 使用独立资源版本查询参数，服务返回 `private, max-age=86400` 和 ETag，支持 304；记忆数据接口仍为 `no-store`。再次打开无需每次重新传输同一个约 39.3 MiB 文件。资源版本由 `release/resources.json` 与加载器共同核对；替换模型时需要更新资源版本。用户模型没有被压缩、降面或修改贴图。

## 取图与兼容

新增两个派生的 SQLite 部分覆盖索引：`memory_atlas_layers`、`memory_atlas_recent`。在数据库中完成层级筛选、配额选取、日期和范围过滤、聚焦优先及可见关系过滤，仅读取选中对象的完整载荷。修复查询计划优先选旧索引的问题，避免总览分组重新读取整表载荷。轨迹游标只统计事件，不再为每次轮询计算整套数据库统计。

分层配额、有效性、归档块排除、未知发生时间、搜索结果上限、焦点优先、同值排序、关系顺序和计数保持既有规则。显示数量仍由原参数决定，没有通过减少星点或降低雾气质量来提速。

数据库结构版本仍为 1：只增加可重建索引，没有更改规范记忆字段、删除原文或迁移聊天。旧版本代码可以忽略这些索引，回退代码无需恢复或覆盖仍在增长的记忆库。部署保留旧模块代码与更新前的数据安全副本；初次打开新版底座需一次性建立索引。

## 验证范围

- 162 项自动检查通过，包含真实帧函数的父窗口焦点、后台暂停、模型初始化延后、同源可见消息、收起/展开保留 iframe、模型缓存与数据不缓存等验证。
- 合成差异验证覆盖 432 个组合：范围、数量、层级、时间、搜索和焦点，匹配旧选择逻辑。
- 在真实底座的私有副本上，约 40,346 条来源、41,718 个对象，18 种视图的完整投影结果哈希均一致。原始生产库只读捕获，基准运行及派生索引建立仅发生在副本中。
- 三轮副本测量的中位值：总览 156.98 → 33.68 ms，取图 331.95 → 14.18 ms。一次性索引初始化约 394 ms。这些是相同副本上的后端方法耗时，不是完整桌面启动时间或显卡耗时。
- DSH 中的部署及页面实测另记本机安装回执，不把合成检查冒充真实宿主全部功能验收。

详细私有测量保存在开发工作区的 `runtime-data/diagnostics`，不进入发布包或 Git 导出仓库。
