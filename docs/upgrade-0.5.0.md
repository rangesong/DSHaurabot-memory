# Thinkstar 0.5.0：反馈修复、总开关与夜间自主学习

设计继续以 V5 为基准。女孩模型、星图空间与既有记忆层级保持；本文描述本版行为和已验证的范围。

## 反馈理解与回复参考

1. 普通新问题、任务指令和日常回答不再仅因发生在回复后30分钟内就收为反馈。真正的模糊反应可以保留，缺少描述的图片不猜含义。
2. 情绪、表达、事实和任务分开记录。内容确认不等于认可表达，事实纠正不再被总标签“未知”遮住，事项催问不当作完成。
3. 表情使用宿主已给出的文字或标题。原始消息中的 summary/description 等描述以来源标签保存，不下载图片或凭文件名想象动作；没有描述时明确待理解。
4. 复杂反馈可在白天后台小批复核，不阻塞QQ主聊天。默认最多每五分钟一批、每批四项，与夜间归纳共用原有每日2次模型额度；批量记忆整理仍在北京时间01:00–06:00进行。额外调用受允许DSH模型的设置约束，失败不会自动无限重试。
5. 对话按准备轮次、宿主turn/start与turn/end绑定。新的主动消息不能借用已结束的旧轮次；只有严格绑定的同一长任务可以超出通常的15分钟关联时间。请求观察只核对当前用户消息中的资料，不把后来请求携带的旧历史再次当作本轮资料。
6. 老反馈渐进重分类，保留原判定历史；普通对话标为已排除，不删原话；错误轮次关联标为待核对。输入引用只包含用户来源，机器人输出另存为回应，避免事实来源校验把整轮反馈拦下。

情境由对应输入和回复共同确定。同一轮中明确纠正、任务催问优先于较晚的模糊玩笑；同一轮多条反应只算一次独立经历。

相似情境可把有依据的纠正、任务状态核对及有界表达建议写进主聊天的“本轮表达参考”。这部分是模块产生的软策略，历史引文仍然只是依据。当前明确要求优先，不以旧反馈断言本轮已完成事项。模型解释产生的“认可”不会自动获得明确认可的事实加深权限。

个人表达解释可在至少3次独立且经过复核的相似经历后，成为有支持来源、版本与条件的暂定知识。用户修订含义会撤回对应加深、停用依赖解释并使旧解释知识失效。不是训练基础模型权重。

## 总开关与栏目

星图标题旁增加“记忆总开关”。关闭时停止Thinkstar的新记录、召回注入、后台整理、模型操作及后续自主工具调用；已有记忆仍可查看，原生记忆模块不受此开关控制。重新开启后处理允许的后续工作。已经提交给提供商的请求不保证立即终止计费。

所有栏目和子栏目继续默认收起，星图默认展开。标题与小图标用对应颜色显示。选用Lucide的脑、网络、数据库、对话、检索、分支、活动、时钟、月亮等图标，对应栏目实际含义；SVG内联在本地面板，没有CDN或新增运行时依赖。来源固定为55782beff3a0133df79c417eb68f96e8f19e2404，ISC与部分Feather衍生图标的MIT许可全文随发布包保留。

## 夜间自省与行动

新增独立可收起栏目，带“夜间自省与行动”开关。发布默认关闭；总开关、参与记忆模式、此开关及允许DSH模型同时开启才运行。

前一天的资料归档和反馈整理返回后，且交接队列已清空，使用同人格主人私聊中前一天的真实资料自问：我现在在想什么、有没有想做的事、有没有想看的东西、今天学到什么、以后如何改善。问答和暂定认识保留来源；同一天同范围持久去重，重启不重复问同一批次。没有资料时不凭空编造一天。

随后真正执行选中的阅读、思考练习或笔记任务。默认每晚1项，可调0–3项，每项等待90秒，可调30–180秒。通过Aurabot自身后台工作会话与现有模型执行，最多6次查询/阅读工具调用；可复用B站简介、字幕及热评阅读接口和贴吧只读接口。宿主原有权限仍有效。此功能不自动发QQ消息、发评论、购物、运行shell或改动其它系统。

阅读必须取得工具返回才计完成；工具不可用、返回失败或只有模型自述，记录未完成/待核对。实际行动结果可作为独立的document来源进入底座，明确标为自主学习观察；自问、兴趣和假设不冒充用户事实。隐私删除同时清除依赖的自省与行动文档。

关闭开关停止新行动和后续工具调用；未开始的已规划任务可在后续夜间继续。中断或失败的在途结果不擅自认定成功。自省记录在对应栏目查看，工具与任务技术记录归运行状态与说明。

## 验证结果

完整隔离回归253项：252通过，1项私人GLB二进制检查因源码仓库不包含该资源而按预期跳过，0失败。覆盖总开关、恢复、参数与面板契约、来源隔离、表情描述、错误轮次、夜间去重、工具回执、错误结果和删除依赖。女孩资源不进入本次代码更新。

用正式库的一致性副本复核先前28条“未知”记录，结果为：11条普通对话排除，2条错误关联待核对；15条保留为反馈，其中14条得到具体分类，1条仍因含义不明确保留待理解。具体分类包括2条事实纠正、1条内容确认、1条事项催问、1条质量反馈，以及模型给出的暂定情绪解释。模糊反应的解释不是人工确认的情感真值。

共16次隔离DSH当前模型调用，包括语境解释、两条真正的历史“摸摸头”及有无反馈建议的输出检查。验证中发现并修复了话题未覆盖回复、玩笑挤掉明确纠正、输入引用混入机器人输出三个额外拦截点。最终由真实主聊天适配器构造的资料包含反馈建议；照片催问的回复明确区分缺少回执与已经发送。未明确要求催饭的相似问题中，模型参考旧纠正选择不继续催促。明确要求它“提醒去吃饭”的问题仍可能得到直接提醒，不能把这种服从当前要求误判成学习失败。

这不是正常QQ投递测试，没有向QQ发送验证消息。两条真实摸头经历不足以证明已形成3次同情境的稳定个人习惯；独立合成回归分别验证门槛、含义修订及后续策略变化。夜间自省与工具执行做了契约和隔离测试，首次真实夜间运行效果仍需后续观察。不能据此保证任意模糊表达均准确理解或证明情感成长。
