# 0.3.1 星图视觉与按钮核对

## 0.3.15：饱满脑形与淡红雾气

旧形状沿用了星区布局包络，实际皮层宽约548、前后厚约377，厚宽比仅0.69。只读检查女孩头部网格后，将脑形的视觉包络独立为BRAIN_VOLUME：中心[0,610,45]、半径[365,280,350]，限制在其0.975倍范围内；原HEAD_VOLUME仍控制星区坐标，记忆点和区域位置不变。新的皮层宽约702、前后厚约643，厚宽比约0.92，前后厚度增加约71%。额顶上部稍作收拢以适配头部收窄，取景计算同时覆盖新包络，保证正面与侧面完整可见。

皮层高光改为淡红色#ffd2d5，沟底为柔和暗红#9e5963，内部雾粒为#edb4bd；远侧表面透明度乘0.55，保留前后层次。增加少量内部雾粒填充体积，仍共享一次点绘制；显示女孩时继续将浓度从0.43降至0.10，并在女孩之前绘制。没有改变星点亮度、原始GLB、模型材质或记忆处理。

## 0.3.14：脑形薄雾、自动旋转与名称开关

全脑外形使用研究启发的程序化立体示意，参考 [UTHealth 神经解剖：半球、脑叶与脑沟](https://nba.uth.tmc.edu/neuroanatomy/L1/Lab01p06_index.html) 和 [NINDS Know Your Brain](https://www.ninds.nih.gov/sites/default/files/2025-05/know-your-brain-brian-basics.pdf)。表现左右半球与纵裂、弯曲的脑回脑沟、中央沟和外侧沟、下后方小脑的平行细褶、脑干及内部弓形结构；并非个体影像重建。以既定 HEAD_VOLUME 为边界，所有顶点限制在其0.975倍范围内，和女孩、星点共用相机、比例、平移、缩放及近裁剪。

几何和法线只在创建时准备；复用现有女孩WebGL渲染器，没有新增画布或渲染器。GLB仍在加载或资源读取失败时可以独立绘制脑雾，女孩继续默认隐藏和预载。灰蓝低饱和薄雾在星点层下方绘制，不参加星点命中；显示女孩时浓度系数从0.43降至0.10，女孩在脑雾之后绘制，原有材质和贴图不变。原貌模式隐藏脑雾。静止时继续复用GPU缓冲，模型隐藏时不会绘制女孩网格；视图销毁同时释放脑雾网格、材质和粒子资源。

左上角增加顺时针旋转开关，默认开启，浏览器减少动态效果偏好下默认关闭；显式选择只作为本地视图偏好保存。速度沿用原生星图的0.05弧度/秒，按实际帧间隔更新，默认一周约126秒。拖动时暂停，缩放、方向调整与拖动后稍作等待；悬停或选中对象、镜头聚焦及二维视图中暂缓。后台沿用暂停机制，恢复后不补转后台时间。

名称开关原本已有事件绑定，区域名称绘制也已有判断；分流说明和L1/L2文字标记遗漏了统一判断，现在一起受控。关闭名称不会去掉星点命中或悬停内容；前台暂停画面中的开关也会直接补绘一帧，后台不因此恢复动画。合成检查覆盖脑内边界、纹理起伏、同一相机/缓存、30/60/120Hz旋转速度、交互暂缓及完整名称隐藏。

2026-11-14。对应本轮四项要求：增强工作中枢/记忆组织雾气，核对神经通道端点，修正右上导航及其他界面入口，删除重复模型显示按钮。本轮没有进行记忆业务功能测试。

## 雾气与星点

工作中枢增加封闭体积雾壳和220个软雾粒；四个记忆组织入口各150个。形状分别采用丘脑双核、弧形前额皮层、杏仁状体积、额下回折叠片、带粗细变化的C形海马体。海马体局部形态倾斜于正面视线，避免正面只剩一根横条；仍保留厚度和深度。这些是解剖启发的艺术近似，不是医学模型。

所有组织/工作雾气先绘制在独立层，再以最高0.60透明度合成，避免粒子叠成白斑。内部结构点、真实记忆星点、端口与活动光点在雾层之后绘制；实际记忆星点的白色亮核最低绘制透明度为0.92。原有七个留存体积、呼吸膜、GLB材质和记忆数据没有改变。

## 通道附着与取景

原来端口一律偏移13个世界单位，没有考虑卵圆核团、皮层与C形管的区别；输入/输出位置也缺少可见节点。这会造成“通道停在空处”的观感。

现在每条通道沿其所属雾壳的实际表面取端口，按目标方向分配，相邻端口保持间隔，并从内部体积接出短支路。输入和输出补上“感知入口”“表达出口”节点，遗忘末端也有可见标记；不增删业务通路。丘脑核群子面板明确列出六个连接对象，其余组织/工作/底座/留存端点使用同一套形状定位。

默认脑内总览按画布尺寸与所有区域范围计算缩放，避免高窗口下两侧端点被推到画外。手动缩放、平移、旋转和进入脑内继续保留。“聚焦头部”与“聚焦底座”现在有不同目标。
