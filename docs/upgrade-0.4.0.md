# Thinkstar 0.4.0：栏目、自然反馈和混合召回

设计基准仍为 V5。工作中枢、四类记忆组织、七种留存投影与统一底座 U 保留。本版继续与 Aurabot 内置记忆协作，未替换宿主或关闭原模块。

## 页面结构

首项名称为“星图”，首次进入默认展开。Thinkstar 记忆、记忆组织、工作中枢、记忆系统、印象、反馈与学习、向量检索、联想与重排、最近活动、最近想起了什么、运行状态与说明均默认收起。星区和所有子栏目也默认收起，不恢复上一次的展开状态。

记忆组织有时间细胞、情景记忆、人物图式、共同基础；工作中枢有丘脑核群、前额皮层、杏仁核、布罗卡区、海马体；记忆系统有近事记忆、巩固记忆、外显记忆、图式记忆、内隐记忆、前瞻记忆、记忆残迹。展开星区先展示介绍和“聚焦此处”，参数与相关内容另设子栏目。留存区域的底座权重共用 U，压缩维护仍归海马体。

原生自动表单改为自定义折叠基础设置，继续使用宿主的 settings/save 接口；没有修改 Aurabot 前端。星图内的完整调参入口定位到主页面相应栏目，独立版仍可直接编辑。多入口共享配置版本、边界检查和回退记录，不维护两份参数。参数是全局默认值；选择范围用于筛选内容，个人条件规则按原范围生效。

最近活动只展示观察到的对话回应或主动互动。仅生成的回复内容、工具查询、任务起止、记忆处理、参数修改、调试、异常和说明全部归运行状态与说明。时间线按实际事件时间倒序、分页读取，重复观察合并并保留阶段历史。模型输出不是 QQ 成功投递回执。

收起栏目卸载其读取与刷新；星图收起保留 iframe/模型并暂停视图。后台记忆接收和召回继续。女孩 GLB、材质、星点、淡红脑雾及相机操作不降级。

## 普通对话与自然反馈

普通 prompt 记录当前范围、输入来源、提供的资料和表达控制。可观察的 DSH 请求完成、session assistant/message 与 turn/end 关联输出；send/activity/chat-log 观察另记发送阶段。没有资料注入时也保留本轮关联，允许在宿主可核对的会话事件中观察最终输出。

用户反应优先通过回复编号关联；私聊可以在可调时间窗内关联同一人的临近互动。群聊缺少明确回复目标时不猜测。消息与来源根去重。反馈区分亲近、表达偏好、事实纠错与任务报告，否定赞许不记为认可，沉默保持未知。QQ 秒级时间戳容许最多一秒的表示精度误差。

“摸摸头”可以是亲近、安慰或玩闹，先存为暂定解释。支持用户明确纠正表达含义；保存解释历史、撤销由误解造成的加深，并停用依赖该解释的互动印象。修订带版本检查。不同主体和聊天不混合学习。

表达学习是可回退的条件策略，不是训练基础模型权重。明确反馈可小幅影响相同情境的表达；模糊反馈达到独立经历门槛才产生更弱的偏移。事实可信度、保护、权限与事项完成状态不受这种偏移影响。当前明确要求优先于旧偏好。

夜间把反复出现的互动归纳为有来源的暂定印象。来源只证明发生过互动，不把模型的判断变成新的独立证据。复杂解释可用 DSH 当前模型，默认每日最多2次、每批最多8项；同一批次只处理同一范围，并复用相同输入结果。停记、范围变化和在途删除在提交前重新检查。未允许宿主模型时仅做本地解释。

## 检索、加深与长期保留

- 词法、实体、本地语义与已有关系参与融合，保留来源回查、重要证据席位、去重和上下文预算。
- 本地使用宿主已安装的 BGE-small 中文 int8、512维 CPU 实现，复用 Thinkstar 实例间的模型缓存；未安装时明确回退词法。没有新增在线向量接口。
- 长原话按220字、40字重叠分段；条件图式额外索引原有触发条件，回到完整对象及原话读取。短查询按 BGE 模型说明加检索前缀。模型、内容与条件参与指纹；仅元数据版本变化不重新计算相同文本。
- 新增及改写的语义索引在夜间增量建立。查询缓存有界，向量按行扫描并让出执行机会，避免一次把全库向量装入内存。当前尚非 ANN 索引，百万级模糊检索仍需单独验证。
- 自动关系扩展受跳数、广度、权重和范围限制。广泛经历包不能无条件带出其它话题；话题只在明确标注或有延续依据时继承。
- 明确正向反馈可跨日、有界加深可达性；仅进入请求不计真实采用，不提高事实可信度。错误反馈解释可撤回增益。
- 可选重排使用 DSH 当前聊天模型，对少量已过滤候选排序；它不是 BGE cross-encoder。默认关闭，开启会增加模型调用，超时回退规则排序。宿主 api.ask 暂不提供取消在途生成的可靠接口，回退不保证提供商立即停止计费。
- 派生全文索引在夜间建立，优先使用有区分度的词筛选候选，防止大量共有词挤入。重复派生对象已经回到同一原话时不再做无意义全文补查。
- 容量改为软预算预警；超过预算仍可靠接收原话，实际磁盘不足明确失败并回滚。不以预算为由静默漏掉重要新消息。

新增参数均有含义、作用及调高调低影响说明。开发样例调试得到的相似度默认门槛0.52不是概率或通用最优值，应结合自己的资料调整；没有提高1536的宿主记忆额度。

## 存储与回退

原有结构版本2、原话、引用去重、版本快照和按年月垃圾桶不迁移、不删减。新增 dialogue_turns、dialogue_feedback、module_activity、semantic_chunks、semantic_documents 以及可重建 FTS 表。旧代码忽略新增表即可读取规范原话。

lookup 触发器令旧写入失效派生索引；新版正常写入在同一事务中更新索引。旧版本运行后再升级，脏索引回退扫描并在夜间重建。明确删除会清除相应向量、FTS、反馈、个人解释知识及派生缓存。仅普通遗忘不自动清空 L0 或垃圾桶。

代码更新先逐文件校验并保留旧模块备份，再交换模块目录；模块数据、宿主配置和私人角色资源不进入交换。需要完整恢复到升级前运行状态时使用相应一致性库备份；不把旧代码回退等同所有学习结果撤销。

## 本次证据及边界

20次相同 DSH 模型合成资料回答，5题×4组：原生3/5、0.3.17为4/5、0.4.0及共同供给为5/5。数字是这组定向小样本的检查结果，不是整体准确率；原生加历史库、开启向量或其它配置可能改变结果。原生缺失的长记事末尾与换说法的特殊偏好是本组差异点。没有向 QQ 发送测试消息，临时模型模块已撤下。

正式库只读副本的4个历史问题均保留目标关键词。旧版额外处理约98–199ms，新版约58–104ms；共同资料约2388–3271字符降至2134–2344字符。两库数据粒度不同，该检查不是完整答案正确性或原生算法的公平容量比较；新版仍有额外开销。

另以405条/日×1095日构造443475条带每日时间戳的历史记录，加入3条跨年份重要原话。重启保真通过；精确事件查询在优化前约4.8–9.3秒，优化后约59–77ms，旧版在相同副本约4.8–9.3秒。隔离库约2.03GiB，整批导入峰值RSS约2.62GiB；不是插件日常占用，也不是实际连续运行三年。没有在这一全量规模下证明任意模糊问题都能准确回答。

本机232项检查通过，反馈、反例、纠正、范围、夜间配额、重启、归档、垃圾桶、视图与宿主契约分别覆盖。不含私人 GLB 的导出仓库231项通过、1项二进制资产检查按预期跳过，代码包验证通过。DSH 已核对默认折叠、星区介绍、参数子栏目及聚焦入口；结果摘要只存入本模块运行说明，没有注入聊天记忆。QQ自然使用的长期学习收益和真实情感增长尚无充分证据。开发调参不是全部参数的穷尽消融。
