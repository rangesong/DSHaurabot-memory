## 安装

1. 将模块文件夹整体复制到当前 Aurabot 数据目录的 `modules/thinkstar-memory/`，确保 `index.mjs`、`module.json`、`engine/` 同层。当前机器对应 `D:\DSH\plugins-data\aurabot\modules\thinkstar-memory`。
2. 将独立资源包中的 `assets/` 复制到 `modules-data/thinkstar-memory/assets/`。模型不放在受监视的代码目录，以免每次热重载都复制大模型。
3. 在 Aurabot“已安装”中确认“Thinkstar 记忆”已启动。进入它自己的面板打开星图。无需启动独立 4318 服务。
4. 默认参与主人私聊的记忆与上下文。群聊、其他私聊由模块设置分别开启。`observe` 模式只积累和查看，不注入上下文，不提供聊天召回工具。
5. 星图中的额外语义整理与面板对话默认关闭；需要时在模块设置中允许调用 DSH 模型，再于星图中明确操作。复用宿主 `api.ask`，不另填或复制密钥。

ZIP 是分发载体；本机审阅的市场安装器按注册表下载模块，不在此承诺有本地 ZIP 上传按钮。可以直接复制已生成的模块文件夹。未发布到市场；本地部署只写指定用户模块与模块数据目录，不覆盖宿主内置源码。

## 数据、更新和回退

- 代码：`modules/thinkstar-memory/`，由构建程序生成。
- 数据：`modules-data/thinkstar-memory/memory.sqlite` 及 SQLite 的 WAL/SHM，由模块独占；代码更新不覆盖它们。
- 垃圾桶：`modules-data/thinkstar-memory/rubbishmemory/2026/2026-11.sqlite`（年份分目录、遗忘年月命名），每月副本库自包含完整恢复材料。
- 迁移备份：`modules-data/thinkstar-memory/backups/before-storage-v2-*.sqlite`；独立保留，计算运行库缩减时不包含它。
- 模型：`modules-data/thinkstar-memory/assets/blue-maid-starry.glb`，跨代码更新保留。
- 现有独立 Thinkstar 数据仍在原项目的 `runtime-data/v5`，本模块不会自动搬走、覆盖或重新归属历史人格。
- 更新前停下 Thinkstar 模块，备份它的代码和数据；替换代码目录后重新开启。0.3.11自动将结构1迁移为2；回退至0.3.10及以前时，必须同时恢复迁移前的一致性旧库备份，旧代码会拒绝新库。
- 单独停下或移走本模块即可撤销接入，会恢复自己包装的原接口，不改变内置模块的开关。保留数据目录即可之后恢复；删除数据必须另行明确操作。

## 与内置记忆的关系

内置 `memory` 继续独立工作；本模块不会更改其开关、配置或业务库。同一对话可能同时收到两者的背景资料，可先使用 `observe` 观察，再按自己的偏好调节两套召回量。本模块不自动关闭其他记忆模块。

非主人内容复用当时运行的内置 `memory.remembers(uid)` 做停记检查；该检查不可用时不召回这些人物的内容。主人私聊可独立运行。停止记住的人物不会通过本模块聊天召回；运行期公开remove和普通私聊遗忘指令会把可定位来源及依赖移入可恢复垃圾桶；deletePerson、带删除的setNoMemory和明确隐私指令清理运行库及相关垃圾桶并阻止恢复；模块停用期间或内部闭包/外部直接改库的删除仍没有完整通知，因此不能宣称全副本擦除已实现。管理星图是本机管理视图，不向聊天工具开放全库视角。

## 已明确保留的边界

- 每次读取模块设置和当前人格，不缓存旧的授权；查询限定到当前人格和聊天。
- `chat/log` 的机器人回复没有生成人格字段，单独存入“人格未归属”的观察范围，不自动冒充当前人格的经历。此事件的文字可能已被宿主截为 500 字，明确标注，不补造完整文本。
- 可读取 DSH tokenMeter、同一路由的 requestContext/requestHeader 时，按会话占用、本轮输入、回答预留和追加误差预留收缩记忆上限。首次请求、路由切换或能力缺失时回退模块上限；估算不冒充精确分词或同轮后续全部内容。
- llm/stream 只读观察同 session、当前人格和聊天的完整证据包，保存最多8份请求边界回执和整次调用用量；不改冻结请求、流块或发送。请求完成不代表实际采用或发送成功，不自动加深；后续中间件和供应商内部处理未独立核验。
- 正常对话仍由 Aurabot 使用自己的模型和发送链处理；额外 `api.ask` 不返回准确 token 用量，界面显示未知。
- 模块热重载先撤销旧实例，取消模型结果提交，等待在途管理请求收尾，再关闭底座，新实例随后接管同一路径。
- 0.3.8 的24项相关合成检查通过；真实DSH已确认会话计量和请求观察服务接入。更新验证未发起远程模型调用或QQ发送，首条新聊天的真实回执仍待正常对话产生；接入成功不冒充生产聊天闭环验收。
- keep_raw_archive默认1；关闭后普通原文可能退出L0，但有损整理/遗忘前先保存完整副本到当月垃圾桶。明确隐私删除不保留可恢复副本；用户另存快照和独立迁移备份属于另行管理范围。
- 相同归档输入/模型/版本复用持久结果；模型调用默认每日6次预留，结果未知不自动重复调用。后台导航仅用本地规则。
- 0.2不理解新归档对象和原文保留语义；降级应恢复升级前配套备份，不能仅换旧代码继续治理同一新库。

## 提供给其他模块

用时调用 `api.use('thinkstar-memory')`，不要缓存旧实例。

| 导出 | 作用 |
|---|---|
| status() | 底座、归档、模型、公开接口同步状态与资源情况 |
| add({chat,text,sourceId}) | 明确chatId/userId的文档记录；不冒充用户原话 |
| addEvent(input) | 优先沿用当前内置接口并同步；没有内置时可记录明确来源的自身经历 |
| noteVia(input) | 委托内置跨渠道入口；运行期保留成功提交的完整输入 |
| contextFor(chat) | 预算内当前状态、自身经历与归档导引 |
| recall(chat,query,options) | 同人格同聊天的来源化候选和上下文；availableTokens可传宿主真实余量 |
| readHistory(chat,options) | level=2月、1日、0原文；支持day/month/keyword/offset/limit |
| remember(chat,{source_id,quote}) | 逐字引用已存在的同范围用户原话 |
| lookupPerson(chat,uid) / chatImpression(chat) | 有限的人物来源材料/M4目录，不能冒充原模块完整人物图谱 |
| associate({chat,id}) | 同范围有界联想，不自动加深 |
| builtin | 动态兼容门面，委托运行中的memory提供其余旧方法 |

默认mirrorBuiltin=true：包装内置公开add/addEvent/noteVia及修订/失效/恢复/删除/停记/记住指令的成功返回，保留原结果，仅同步本模块库。无聊天的自身经历独立存放，只有主人私聊在预算内读取；不猜其它未归属事实的人物和聊天。关闭镜像只停止新增镜像；运行期删除/停记保护继续执行。

停止模块时只恢复仍由本模块持有的包装。原模块内部闭包自行调用、停用期变更和不经公开方法的写入不保证被观察。builtin仍依赖原memory运行；未实现其全部画像/向量算法的独立替代，也不注册同名旧工具来碰撞它们。不要将本模块改名为memory。

0.3.2 优化后台按需统计、星图读取与静态模型重绘；仍为协作模块，不能关闭内置 memory 后保证全功能替代。详见开发仓库 docs/compatibility-performance-0.3.2.md。

## 0.7.0 经验自动成熟

独立反馈图式可在夜间自动进入内隐表达准则，保留同一规范ID与完整原证据。默认至少3次已复核的同情境独立经历，分布在2个北京时间自然日；先小幅试用，由后续新反馈验证。当前支持简洁程度、追问压力、贴近与接住安慰／玩闹的表达方式。面板提供默认收起的成熟与验证依据、暂停和撤回，暂停内容不通过普通召回或缓存继续参与表达。详细门槛、边界和恢复见[自动成熟设计](https://github.com/rangesong/DSHaurabot-memory/blob/main/docs/automatic-implicit-learning.md)。
